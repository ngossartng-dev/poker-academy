# Poker Academy

Appli d'entraînement au poker de tournoi : ranges par profil, exercices, parties contre des adversaires typés, cours en 32 leçons avec podcasts, et analyse des mains Winamax et du club.

**Ouvrir l'appli :** https://ngossartng-dev.github.io/poker-academy/

- **iPhone** : ouvrir le lien dans Safari, bouton Partager, « Sur l'écran d'accueil ».
- **Android** : ouvrir le lien dans Chrome, menu ⋮, « Installer l'application » (ou utiliser l'APK).
- **PC** : l'exécutable Windows est fourni à part.

Les données (joueurs, progression, mains importées) restent sur l'appareil.
