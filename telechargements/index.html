iPhone et iPad

Pas de téléchargement : l’appli s’ouvre dans Safari et s’ajoute à l’écran d’accueil.

  1. Ouvre le lien ci-dessous dans Safari.
  2. Touche le bouton Partager (le carré avec une flèche).
  3. Choisis « Sur l’écran d’accueil », puis « Ajouter ».

Android

Télécharge l’APK, ouvre-le, puis autorise l’installation depuis cette source si le téléphone le demande. Pour mettre à jour, installe le nouvel APK par-dessus : tes données sont conservées.

PC Windows

Télécharge l’installateur et lance-le. Windows peut afficher « Windows a protégé votre ordinateur » : clique sur « Informations complémentaires », puis « Exécuter quand même ».
